# Desafios Python 🐍

Repositório dedicado a desafios e exercícios desenvolvidos durante meus estudos de **Python e lógica de programação**.

O objetivo deste repositório é registrar minha evolução na linguagem, reunindo exercícios selecionados que exploram diferentes conceitos e formas de resolução de problemas.

## 📂 Organização

Os desafios estão separados de acordo com os principais conceitos praticados:

- `01-fundamentos` — operações, entrada de dados, módulos e conceitos iniciais
- `02-condicionais` — estruturas condicionais e tomada de decisões
- `03-repeticoes` — estruturas `for`, `while`, acumuladores e algoritmos
- `04-tuplas` — manipulação e processamento de tuplas
- `05-listas` — listas, inserção, ordenação e validação de dados

## 🧠 O que estou praticando

- Lógica de programação
- Estruturas condicionais
- Estruturas de repetição
- Manipulação de strings
- Tuplas e listas
- Validação de dados
- Construção de algoritmos

## 🚀 Evolução

Este repositório será atualizado conforme avanço nos estudos e desenvolvo novas soluções.

Alguns desafios podem possuir abordagens diferentes, permitindo acompanhar minha evolução na resolução de problemas.
